# OVOLL

Premium Digital Growth Platform built with Laravel 13, React 19, Vite, and Tailwind CSS v4.

## Tech Stack
- **Backend**: Laravel 13, PHP 8.4+, MySQL, Filament v4
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4
- **Libraries**: GSAP, Three.js, React Three Fiber, Drei, Lenis, Framer Motion, React Hook Form, Zod, Lucide React

## Development Server
To start the development servers:
```bash
npm run dev
# or
composer run dev
```

## Production Build
```bash
npm run build
```
