# OVOLL --- Design System

## Foundations

-   12-column responsive grid
-   8px spacing scale
-   Consistent border radius
-   Consistent shadow system

## Colors

Primary - #081320 (Deep Navy) - #FFFFFF (White)

Accent - #14B8A6 (Teal) - #00D1FF (Electric Cyan)

## Typography

-   Large editorial headings
-   Comfortable reading width
-   Clear hierarchy
-   Consistent line heights

## Components

Every component supports: - Hover - Focus - Loading - Success - Error -
Disabled - Empty

## Buttons

Primary, Secondary, Ghost, Link. Consistent hover and focus states.

## Cards

Glass, premium shadows, subtle borders, refined hover.

## Motion

Durations: 200, 300, 500, 800, 1200ms

Use one easing family across the product.

## Accessibility

WCAG AA+ Keyboard navigation ARIA Reduced motion Semantic HTML
